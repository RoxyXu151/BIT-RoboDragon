# BIT-RoboDragon

**简体中文** | [English](README.en.md)

北京理工大学屠龙智能车挑战赛 Arduino 控制程序，包含蓝牙遥控、红外循迹、超声波避障，以及版本相关的发射机构或舵机控制。

## 环境要求

Arduino UNO、Arduino IDE、对应驱动与串口；舵机版需要 Servo 库及匹配硬件。

## 获取仓库

```bash
git clone https://github.com/RoxyXu151/BIT-RoboDragon.git
cd BIT-RoboDragon
```

私有仓库需要先通过 GitHub 认证。以下相对路径与操作均以本仓库为起点。

## 安装与启动

本项目按下方说明使用对应编辑器或阅读工具；当前没有统一的命令行启动步骤。

## 配置与准备

分别打开 bth_v2/bth_v2.ino 或 tulong/tulong.ino，选择 UNO 和正确串口。两版 leftPWM、红外与 shoot 引脚不同；接线必须以选定 sketch 顶部定义为准，不混用。串口波特率为 9600。

## 使用方法与产物

先编译再上传，按已选程序的模式流程测试。遥控字符 F/B/L/R/S 分别对应前进、后退、左右转和停止；A 为基础版执行机构，E 为舵机版控制。C/D 模式退出行为以 sketch 实现为准。

## 验证与常见问题

先检查轮子悬空时的方向和停止行为，再低速验证传感器阈值、循迹和避障。串口占用时关闭监视器后重试上传。当前无硬件自动化测试。
